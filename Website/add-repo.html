自動で開かない場合

  1. 上の「VCC を開く」ボタンを押してください。確認画面が表示されたら、起動を許可してください。
  2. それでも開かない場合は VCC を手動で起動し、Settings → Packages → Add Repository を開きます。
  3. 上のリポジトリ URL を貼り付け、Add を押します。
  4. リポジトリ名が「sjcl」であることと URL を確認し、I Understand, Add Repository を押してください。

VCC が未インストールの場合は、公式サイトからインストールして、もう一度お試しください。

If VCC does not open automatically

  1. Click Open VCC above. If your browser asks, allow it to open the application.
  2. If it still does not open, launch VCC manually and go to Settings → Packages → Add Repository.
  3. Paste the repository URL shown above and click Add.
  4. Check that the repository is named sjcl and the URL is correct, then click I Understand, Add Repository.

If VCC is not installed, install it from the official website, then try again.
