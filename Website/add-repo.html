自動で開かない場合

  1. 上の「VCC / ALCOM を開く」ボタンを押してください。確認画面が表示されたら、起動を許可してください。
  2. それでも開かない場合はアプリを手動で起動し、VCC では Settings → Packages → Add Repository、ALCOM では パッケージ&テンプレート → VPMリポジトリを追加 を開きます。
  3. 上のリポジトリ URL を貼り付け、確認画面へ進みます。
  4. リポジトリ名が「sjcl」であることと URL を確認し、追加を確定してください。

If VCC / ALCOM does not open automatically

  1. Click Open VCC / ALCOM above. If your browser asks, allow it to open the app.
  2. If it still does not open, launch the app manually. In VCC, go to Settings → Packages → Add Repository. In ALCOM, go to Resources → ADD REPOSITORY.
  3. Paste the repository URL shown above and continue to the confirmation screen.
  4. Check that the repository is named sjcl and the URL is correct, then confirm adding the repository.
