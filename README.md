# sjcl VPM Repository

sjcl の VRChat 向けパッケージを VCC / ALCOM で配布する VPM リポジトリです。

- 配布ページ: <https://vpm.sjcl.me/>
- リポジトリ URL: <https://vpm.sjcl.me/index.json>

GitHub Releases の ZIP から配布一覧を生成し、Cloudflare Pages に公開します。
